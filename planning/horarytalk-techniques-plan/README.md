# HoraryTalk 점성술 기법 백과 계획 패키지

2026-09-18 조사·설계 자료. **웹사이트 코드·실행 가능한 크롤러·번역 완료 코퍼스·배포 결과가 아닙니다.**

## 파일

- REPORT_KO.md: 제품·편집·권리·번역·아키텍처·실행 단계·배포 전 검증 보고서.
- IMPLEMENTATION_HANDOFF.md: 후속 구현자의 작업 순서와 중단 지점.
- TOPIC_CATALOGUE.md: 455개 탐색 후보의 사람이 읽는 목록.
- topic_seeds.json: 동일 후보의 구조화 목록. 한국어 명칭은 가안이며 공개가 기본 차단됩니다.
- source_registry.json: 37개 자료원/설계 참고 기록. 본문 접근 실패·검색 결과만 확인한 기록도 상태로 구분합니다.
- schemas/: 위키 문서·권리 결정·번역 작업 JSON Schema 설계안.
- VALIDATION.json: 이 계획 자료의 JSON/ID/스키마 검사 결과. 서비스 테스트 결과가 아닙니다.
- MANIFEST.json: 패키지 파일의 SHA-256.

후보는 기법·개념·학파·문헌·인접 점복까지 포함합니다. 후보 수를 검증된 기법 수 또는 완성 문서 수라고 표시하지 마십시오. source hint는 탐색 입구이며 해당 후보의 주장 근거로 확인된 인용이 아닙니다.

기존 프로젝트·운영 DNS·Worker·데이터베이스·비밀키는 수정하지 않았습니다. 이 패키지는 채팅 작업 공간에서 생성했습니다.
