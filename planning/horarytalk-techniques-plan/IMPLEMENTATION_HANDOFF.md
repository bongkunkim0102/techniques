## 결정된 설계 방향

공개 읽기는 Astro 정적 HTML을 기본으로 하고, 필요한 부분만 React로 상호작용을 추가한다. 승인 원고의 권위는 Markdown/JSON 버전 저장소에 둔다. 편집 DB는 작업·제안·파생 인덱스만 관리한다. 원문과 비밀키는 코드·공개 자산과 분리한다. 공개 페이지 방문마다 LLM·원문 사이트·사용자 PC에 의존하지 않는다.

수집기는 허가 확인을 통과한 주소만 처리하며 내부망 주소/메타데이터 URL 접근을 차단한다. 별도 원문 저장소는 자동 배포 경로에 두지 않는다. 수집 텍스트를 명령으로 실행하지 않는다. 외부 MDX 실행을 허용하지 않는다.

## 권고 작업 단위

### W01 — 문서 계약·출처·권리

이 패키지의 schema는 초안이므로 실제 저장 규약과 validator를 정리한다. Work/Edition/SourceSnapshot/Claim/TechniqueVariant를 분리한다. 핵심 규칙은 어떤 판본의 어느 구간에서 나왔는지 가리켜야 한다. 모든 공개 콘텐츠는 라이선스와 개인정보 검토를 통과해야 한다.

통과 조건: JSON schema 검사, 문서 ID/출처 ID/관계 해소 검사, 같은 이름의 다른 개념 구분, 출처가 없는 규칙 차단, 권리 미확정 자료의 공개 차단.

### W02 — 한국어 용어집과 대표 콘텐츠

455개 후보에서 30개 대표 문서를 정한다. 서양 고전뿐 아니라 현대·인도·동아시아·티베트·공통 계산을 포함한다. 한국어 권장어를 확정하기 전에는 영문/원어를 병기한다. 가이드상 기존 코퍼스는 실제 원본을 열어 권리·중복·개인정보·구분자·스키마를 검증한다.

통과 조건: 최소 한 개의 각 대표 흐름이 수집→원문 근거→번역→편집→검색→관련 문서까지 연결된다. 설명·역사·판단 규칙·계산·효과 연구의 주장을 구분한다.

### W03 — 입력·추출·번역 작업기

페이지·문단·영상 시각 locator와 내용 해시를 보존한다. 허용 자료만 원문 저장하며, 미허가 자료는 서지와 링크로 남긴다. source_hash/glossary_version/prompt_version/policy_version으로 작업 키를 만든다. 중단·재시도·체크포인트를 구현한다.

제공될 Camel API의 실제 사업자와 계약을 확인한다. 표준 Camel Stream의 데이터 조항을 자동 승인으로 간주하지 않는다. 동일 계정의 여러 키는 하나의 동시성 예산을 공유한다. 전역 우선순위를 원한다면 기존 호출자도 같은 조정기를 쓰는지 확인한다. 차트 판단 전용 API에 번역 문서를 억지로 넣지 않는다.

통과 조건: 큐 중복 요청 방지, 401/402 중단, 429 Retry-After, 503 지연재시도 상한, 입력 해시 중복제거, 외부전송 불허자료 차단, 모델 보고값과 요청값 분리.

### W04 — 공개 페이지·검색·비교

홈, 기법 문서, 학파별 목록, 적용 분야별 목록, 용어집, 비교 문서, 출처, 이력, 수정 제안 경로를 구현한다. 처음부터 완전한 익명 편집 CMS를 만들 필요는 없다. 페이지 HTML에 본문이 있어야 한다.

Pagefind와 제목/동의어 인덱스를 연결한다. 한국어 조사·띄어쓰기·영문·한자를 포함한 100개 질의를 평가한다. 그래프는 제한된 주변 관계부터 보여준다. 모바일에서 가로 넘침 없이 읽을 수 있어야 한다.

### W05 — Astrocode 예제

실제 사용 가능한 계산 함수·직렬화 계약을 먼저 확인한다. 현재 파일명만으로 해당 기법의 지원을 선언하지 않는다. 예제 입력·규약·코드 버전·기대값·오차·출력 해시를 저장한다. 합성 또는 동의된 자료만 공개한다. 지원하지 않는 옵션은 미지원으로 표시한다.

Swiss Ephemeris와 차트 글꼴·기호·도판의 라이선스를 실제 배포 조건에 맞게 검토한다. 기존 상용 자산을 새 위키로 복사하지 않는다.

### W06 — 편집과 발행

제안→검토→승인 후보 상태를 만들고 source revision 충돌을 검사한다. 자동 승인 금지. 사람의 승인 기록을 AI 검수 기록과 분리한다. 각 공개 버전에 고정 인용 주소를 부여한다. 기존 Chat과 연결할 때 공개/비공개 채널 권한이 새지 않는지 검증한다.

### W07 — 배포 직전 패키지

정적 빌드, 검색 인덱스, 승인 원고 manifest, 라이선스 목록, 실제 테스트 결과, 안전한 예제, 배포 절차와 롤백을 만든다. 새 위키만 대상으로 한 scoped scripts를 사용하고 루트 전체 서비스를 불필요하게 빌드/배포하지 않는다.

## 출시 차단 조건

권리 미확정 본문/도판, 개인자료 노출, 허위 출처, 부정·주야·순역의 번역 반전, 수식/기대값 불일치, 미지원 기능을 성공으로 표시, 공개 파일 내 비밀키, 인증 우회, 승인하지 않은 초안의 검색 노출은 출시 차단이다.

## 반드시 멈출 지점

사용자가 별도 운영 배포를 승인하기 전에는 DNS/도메인 연결, production Worker 배포, production secrets 등록, 원격 D1/R2 생성 또는 수정, Git push를 하지 않는다. 로컬 dry-run을 운영 완료로 보고하지 않는다. 테스트는 실제 실행한 항목·명령·결과만 보고한다.

이 패키지의 `VALIDATION.json`은 계획 자료의 JSON 형식과 참조를 검사한 결과일 뿐, 미래 웹사이트 테스트 결과가 아니다.
