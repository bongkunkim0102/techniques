# 1908 Kommentar 새 번역용 보충 용어집

판: 2026-09-20.astra-restart.1. 기존 공유 용어집 652항목(2026-09-18.6)과 마닐리우스 문헌별 항목을 읽고 마련했다. 공유 전역 용어집은 수정하지 않는다. 아래는 이번 새 번역판에 딸린 추가 독해 항목이며, 기존의 역사적 번역 판 번호를 바꾸지 않는다.

| 원문 | 한국어 | 이번 번역의 정의·주의 |
| --- | --- | --- |
| Lesart, lectio | 독법 | 사본 또는 편집본에서 읽히는 구체적인 문자·어구. 뜻풀이와 구별한다. |
| Konjektur, coniectura | 추정 교정 | 사본의 직접 증거가 아니라 문맥·운율·문법을 근거로 제안한 교정. 채택 여부와 제안자를 보존한다. |
| Überlieferung | 전승 | 텍스트가 사본·판본을 통해 전해진 상태. Breiter의 판단을 현대의 확정 사실로 바꾸지 않는다. |
| Handschrift, codex | 사본 | 본문을 전하는 필사 자료. g·l·m·c 등 표지는 그대로 유지한다. |
| Interpolation | 삽입; 삽입으로 보는 구절 | 주석가가 후대에 들어왔다고 판단하는 구절. 주석가의 주장임을 명시하며 임의 삭제하지 않는다. |
| Dittographie | 중복 필사 | 한 번 쓸 대목을 잘못 거듭 적는 필사 현상. 서로 다른 서술을 임의로 중복이라 판정하지 않는다. |
| Lemma | 주석 표제; 주석 대상 어구 | 해당 설명이 대상으로 삼는 행 번호·어구. 시 전체의 장 번호나 번역 문단 수와 다르다. |
| praeteritio | 생략 선언의 수사법 | 어떤 일을 말하지 않겠다고 하면서 언급하는 표현. 실제 번역의 생략을 허용하는 지시가 아니다. |
| positio debilis | 약한 위치장음 | 운율 논의의 전문어. 여기서는 특정 자음 결합에 의한 음절 길이 처리와 관련한 Breiter의 평가를 옮긴다. |
| δοξαί, placita | 학설; 견해 | 자연의 기원 등에 관해 병렬로 소개하는 견해들. 인용된 학자의 견해와 Breiter의 평가를 분리한다. |
| ἐκπύρωσις | 우주적 대화재 | 스토아 우주론의 불에 의한 세계 소멸·갱신 문제. 원문이 특정 인물의 부정 여부를 말하면 그대로 옮긴다. |
| Concinnität | 균제; 문장 균형 | 어구·문장 성분을 가지런하게 맞추는 문체적 균형. 논리적 정합성 전체와 동일시하지 않는다. |
| Anakoluthie | 구문 불연속 | 문장을 시작한 구조와 뒤의 연결이 어긋나는 현상. 번역자의 실수로 오인하지 않도록 표시한다. |
| Siglen | 사본·판본 약호 | o와 ω, l과 숫자1, u₁·u₂를 구별하며 원문에 설명되지 않은 약호의 의미는 추정하지 않는다. |

기존 용어의 재사용: 적경(right-ascension), 적위(declination), 세차(precession), 황경·황위, 사인과 별자리, 문두스, 라티오, 운명과 포르투나, 템플라·아틀라의 구별. 주석이 특정 라틴어를 행성·항성 등으로 해석하는 곳에서는 기존 항목을 이유로 그 해석을 바꾸지 않는다.

사인·항성의 고유명은 첫 출현에 한국어와 원어를 함께 적고 이후 일관되게 사용한다. 라틴어·그리스어 인용과 서지 약호는 보존하며, 뜻을 덧붙일 때에는 괄호로 구별한다. 본문에서 ‘나’는 Breiter이다. 번역자의 판단은 반드시 [새 번역자 주]로 분리한다.
